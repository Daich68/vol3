# Vol-3 / Web-Almanac — моушн-рилс для портфолио

Вертикальный ролик 9:16 (1080×1920, 30 fps, 34 с, H.264 + AAC) — презентация
интерфейса [vol-3.web-almanac.com](https://vol-3.web-almanac.com/) в формате
Reels для портфолио/резюме дизайнера.

**Готовый файл:** [`out/vol3-reel.mp4`](out/vol3-reel.mp4) · обложки:
[`out/cover-hero.jpg`](out/cover-hero.jpg), [`out/cover-end.jpg`](out/cover-end.jpg)

Всё собрано из этого репозитория: шрифты (Entropia, DeltaBlock, Babayka),
пиксельный логотип, `circle.svg`, `scroll.svg`, ветки `01.png`, видео дерева,
GIF-глифы словаря, а саундтрек — `src/static/sound/vol3.wav` (120 BPM), под
его сетку поставлены все склейки. Экраны сняты с локальной сборки приложения.

## Раскадровка

| Время | Сцена | Что происходит |
|---|---|---|
| 0:00 | **01 Preloader** | кольцо-ветка заполняется конусной маской, счётчик 000→100, логотип собирается из пикселей, выход как в `Preloader.tsx`: лого ×20 + blur, панель уезжает вверх — **дроп** на 2.0 с |
| 0:02 | **02 Hero** | PageFrame рисует свои линии, стекло, сайдбар с веткой-скроллом и узлом прогресса; WEB-ALMANAC поднимается из масок, призрачный логотип заливается снизу, ветки заползают из углов; на долях — глитч-сдвиги и такт в Backslant-начертании; нырок в штамб буквы «L» до чёрного |
| 0:06 | **03 Rules** | карточки 01 / ∞ / 00 (одометр, лемниската рисуется штрихом, скрембл) → работают как степ-секвенсор на сильных долях → схлопываются в луч |
| 0:10 | **04 Tree navigation** | ствол растёт, ветки выстреливают на восьмых, курсор-спираль наводится на «записи» (видео в `mix-blend: difference`), клик настоящим `button.wav` → карточка раскрывается на весь экран, видео поворачивается в портрет и становится органической рамкой |
| 0:14 | **05 Screens** | реальные экраны: телефон в рамке из веток (журнал → список → режим чтения), затем десктоп + телефон на «жидком» фоне (поиск, автор, словарь), затем изометрическая стена всех экранов и нырок в главный |
| 0:20 | **06 Architecture** | тот же экран, разобранный на 5 настоящих слоёв (фон, рамка, контент, ветка-скролл, объекты) в изометрии, легенда подсвечивает слои на долях |
| 0:24 | **07 Personal language** | «свой язык» пишется от руки (Babayka), 12 GIF-глифов на шестнадцатых, пост с глифом и тултип `SYNTAX_DECODE`, чернила тултипа заливают экран |
| 0:28 | **08 The path** | «это не гонка.» (зачёркнуто) → вспышка → «это путь.», электрическая ось; финальная карточка: логотип снова собирается из пикселей, кольцо замыкается, кредиты |

Сквозные приёмы: HUD в стиле `.header-details` сайта (угловые метки,
`INDEX.VOL_3`, таймкод, номер сцены), курсор повторяет `CustomCursor.tsx`,
«панчи» камеры на сильных долях, motion blur 180° (5 субкадров на кадр),
лёгкое плёночное зерно, звуковой дизайн (тики, вуши, импакты, блипы в
тональности трека) синтезируется скриптом и ставится на те же метки, что и
анимация.

## Как это устроено

```
portfolio-reel/
  index.html, reel.css, reel.js   композиция 1080×1920: один GSAP-таймлайн на паузе
                                  + «драйверы» (чистые функции времени) — любой кадр
                                  можно получить через window.__reel.seek(t)
  assets/screens/                 экраны приложения (d-* десктоп, m-* мобильный,
                                  d-layer-* — прозрачные слои главной страницы)
  assets/sprites/                 видео, GIF и ветки, запечённые в спрайты
  scripts/capture-screens.mjs     снимает экраны с `yarn build` через Playwright
  scripts/mock-api.mjs            демо-контент для записей/поиска/профиля
  scripts/build-sprites.mjs       спрайты из public/*.mp4, src/static/icons/*.gif, 01.png
  scripts/render.mjs              покадровый рендер + motion blur + звук → MP4
  scripts/audio.mjs               саунд-дизайн поверх vol3.wav
  scripts/stills.mjs              отдельные кадры/контакт-лист для проверки
```

> Контент на экранах «записи», «поиск» и «профиль» — демонстрационный
> (`scripts/mock-api.mjs`): во время съёмки продовый API был недоступен.
> Чтобы снять с реальными данными, уберите `context.route(...)` в
> `capture-screens.mjs` и перезапустите съёмку.

## Просмотр в браузере

```bash
yarn install                 # нужен gsap из node_modules
npx serve .                  # из корня репозитория
# открыть http://localhost:3000/portfolio-reel/  (пробел — play/pause, ползунок — скраб)
# ?t=12.5 — открыть на нужной секунде
```

## Рендер

Нужны Node 18+, `ffmpeg` с libx264 и Chromium для Playwright:

```bash
npm i -g playwright && npx playwright install chromium   # один раз
node portfolio-reel/scripts/render.mjs                   # → portfolio-reel/out/vol3-reel.mp4
```

Полезные флаги: `--credit "design & motion — Имя Фамилия"` (строка на
финальной карточке), `--from 10 --to 14` (кусок), `--samples 1` (без motion
blur, быстро), `--workers 4`, `--crf 18`, `--grain 0`, `--no-audio`.

Кадры для проверки: `node portfolio-reel/scripts/stills.mjs --sheet 2.2 6.5 12.4`.

Переснять экраны и спрайты:

```bash
yarn build
node portfolio-reel/scripts/capture-screens.mjs
node portfolio-reel/scripts/build-sprites.mjs
```

## Для Instagram

Загружать как Reels без кадрирования. Громкость сведена к −14 LUFS. Обложку
можно взять из `out/cover-*.jpg`; ещё хорошие кадры: 0:08 (карточки 01/∞/00)
и 0:22 (разобранные слои). Нижние ~15% кадра в Reels перекрывает подпись —
ключевой контент держится выше, внизу только HUD.
