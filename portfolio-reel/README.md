# Vol-3 / Web-Almanac — моушн-рилс для портфолио

Вертикальный ролик 9:16 (1080×1920, 30 fps, 42 с, H.264 + AAC) — презентация
интерфейса [vol-3.web-almanac.com](https://vol-3.web-almanac.com/) в формате
Reels для портфолио дизайнера.

**Готовый файл:** [`out/vol3-reel.mp4`](out/vol3-reel.mp4) · обложки:
[`out/cover-hero.jpg`](out/cover-hero.jpg), [`out/cover-dict.jpg`](out/cover-dict.jpg),
[`out/cover-end.jpg`](out/cover-end.jpg)

Чёрно-белый, как сам проект, без HUD-рамок и надписей поверх: в кадре только
интерфейс. Лендинг пересобран в точных пропорциях телефонной вёрстки сайта
(сцена 1080×1920 — это ровно экран 432×768 при 2.5x), а скролл-ветка,
заметки и словарь — настоящее приложение из этого репозитория, снятое
покадрово (`scripts/record.mjs`). Шрифты, логотип, `circle.svg`,
`scroll.svg`, видео дерева, GIF-глифы — из репозитория; саундтрек —
`src/static/sound/vol3.wav` (120 BPM), под его сетку поставлены склейки,
клики — звук кнопки сайта `button.wav`.

## Раскадровка

| Время | Сцена | Что происходит |
|---|---|---|
| 0:00 | Прелоадер | кольцо-ветка заполняется, счётчик 000→100, логотип собирается из пикселей, выход как в `Preloader.tsx` — дроп на 2.0 с |
| 0:02 | Главная | рамка страницы рисует себя, WEB-ALMANAC поднимается из масок, призрачный логотип заливается, на ветку садится узел скролла; камера ныряет в узел |
| 0:05 | Скролл-ветка | из узла — в настоящий сайдбар сайта: каждый щелчок колеса переворачивает страницу, узел с процентом едет по ветке 20 → 50 → 80 %, ветка заливается светом |
| 0:08 | Правила | 01 / ∞ / 00 в реальном размере карточек: одометр, лемниската рисуется штрихом, скрембл; на долях карточки инвертируются; страница переворачивается — узел уезжает на 80 % |
| 0:12 | Навигация | карточки дерева навигации падают на восьмых, палец нажимает «записи», карточка раскрывается в видео дерева |
| 0:14 | Заметка | телефон в органической рамке: журнал, список, заметка открывается и пролистывается до конца в режиме чтения |
| 0:19 | Все экраны | стена десктопных экранов, нырок в главную |
| 0:21 | Слои | та же страница, разобранная на 5 настоящих слоёв в изометрии |
| 0:25 | Словарь | «синтаксис мира», 12 глифов на шестнадцатых; на телефоне: глифам дают свои значения и закрепляют, в новом посте при выборе глифа всплывает твоё значение, публикация, читатель нажимает на глиф — `SYNTAX_DECODE` с этим значением |
| 0:36 | Финал | логотип собирается в кольце, два QR — [t.me/vastu_sastra](https://t.me/vastu_sastra) и [vol-3.web-almanac.com](https://vol-3.web-almanac.com/) |

Сквозные приёмы: «панчи» камеры на сильных долях, скорость живых записей
меняется плавными рампами, motion blur 180°, лёгкое зерно, звуковой дизайн
(тики, вуши, импакты, клавиатура) ставится на те же метки, что и анимация.

## Как это устроено

```
portfolio-reel/
  index.html, reel.css, reel.js   композиция 1080×1920: один GSAP-таймлайн на паузе
                                  + «драйверы» (чистые функции времени) — любой кадр
                                  можно получить через window.__reel.seek(t)
  assets/screens/                 экраны десктопа для стены и слоёв (capture-screens.mjs)
  assets/sprites/                 видео дерева и GIF-глифы спрайтами (build-sprites.mjs)
  assets/qr/                      QR-коды финала (make-qr.mjs)
  scripts/record.mjs              покадровая съёмка приложения на виртуальных часах
  scripts/timeshim.js             виртуальное время страницы (Date, rAF, таймеры,
                                  CSS/Web Animations, <video>, GIF)
  scripts/takes.mjs               сценарии дублей: куда скроллить, что нажимать, что печатать
  scripts/mock-api.mjs            данные для съёмки (демо или реальные из data/api.json)
  scripts/fetch-api.mjs           скачать реальные данные сайта
  scripts/render.mjs              покадровый рендер + motion blur + звук → MP4
  scripts/audio.mjs               саунд-дизайн поверх vol3.wav
  scripts/stills.mjs              кадры/контакт-лист для проверки
```

Дубль — JPEG-последовательность 60 fps в `.cache/takes/<дубль>/` и
`track.json` (палец/курсор, нажатия, клавиши, положение узла скролла).
В ролике используются `d-home` (сайдбар), `m-notes` и `m-dict`.

## Данные

Заметки, профиль и словарь в текущем рендере — **демонстрационные**: продовый
API (`vol3.web-almanac.com`) был недоступен из среды, где собирался ролик;
демозаметка собрана из текстов страницы «философия». Чтобы переснять с
настоящими данными — тогда в заметках откроется заметка Данилы Кудимова:

```bash
yarn build
node portfolio-reel/scripts/fetch-api.mjs          # → portfolio-reel/data/api.json
node portfolio-reel/scripts/record.mjs d-home m-notes m-dict
node portfolio-reel/scripts/render.mjs
```

## Просмотр и рендер

Нужны Node 18+, `ffmpeg` с libx264 и Chromium для Playwright
(`npm i -g playwright && npx playwright install chromium`).

```bash
yarn install && yarn build
node portfolio-reel/scripts/record.mjs --dry       # быстрый прогон сценариев
node portfolio-reel/scripts/record.mjs d-home m-notes m-dict
node portfolio-reel/scripts/stills.mjs --sheet 5.6 9.5 28.8 35.5
node portfolio-reel/scripts/render.mjs             # → portfolio-reel/out/vol3-reel.mp4
```

Превью в браузере: `npx serve .` из корня репозитория →
`http://localhost:3000/portfolio-reel/` (пробел — play/pause, `?t=12.5` —
открыть на нужной секунде). Флаги рендера: `--from 10 --to 14` (кусок),
`--samples 1` (без motion blur, быстро), `--workers 4`, `--crf 18`,
`--grain 0`, `--no-audio`.

## Для Instagram

Загружать как Reels без кадрирования. Громкость сведена к −14 LUFS. QR-коды
на финале держатся около четырёх секунд и стоят выше подписи и в стороне от
кнопок справа — их можно отсканировать с паузы или скриншота.
