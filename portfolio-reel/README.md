# Vol-3 / Web-Almanac — рилс для портфолио

Вертикальный ролик 9:16 (1080×1920, 30 fps, 38 с, H.264 + AAC) — презентация
интерфейса [vol-3.web-almanac.com](https://vol-3.web-almanac.com/) в формате
Reels.

**Готовый файл:** [`out/vol3-reel.mp4`](out/vol3-reel.mp4) · обложки:
[`out/cover-hero.jpg`](out/cover-hero.jpg) (скролл-ветка),
[`out/cover-dict.jpg`](out/cover-dict.jpg) (словарь),
[`out/cover-end.jpg`](out/cover-end.jpg) (QR)

В кадре только настоящий интерфейс. Приложение из этого репозитория
(`yarn build`) снято покадрово в Chromium: прелоадер, скролл, ховеры, клики и
набор текста происходят в живом приложении, с его анимациями, видео и
GIF-глифами. Ничего не перерисовано, поверх картинки нет надписей и рамок;
чёрно-белое, как сам проект. Музыка — `src/static/sound/vol3.wav` (120 BPM),
клики — звук кнопки сайта `button.wav`.

## Раскадровка

| Время | Что происходит |
|---|---|
| 0:00 | Прелоадер на телефоне (ускорен), на первой сильной доле — главная |
| 0:04 | Склейка по заголовку WEB-ALMANAC с телефона на десктоп |
| 0:05 | **Кастомный скролл.** Скроллбар — ветка в сайдбаре: страница щёлкает по трём состояниям, ветка заливается светом, узел с процентом и кольцом прогресса едет по ней 20 → 50 → 80 % (камера подъезжает к сайдбару) |
| 0:08 | Навигация-дерево → клик по «записи» |
| 0:11 | Заметки: список-ветка, ховер с видео, режим чтения — здесь прогресс линейный, узел ведёт по ветке до конца текста |
| 0:18 | **Личный словарь** (телефон): «синтаксис мира» — глифам дают свои значения и закрепляют; новый пост — при выборе глифа всплывает твоё значение; публикация; тап по глифу в ленте — читатель видит `SYNTAX_DECODE` с этим значением |
| 0:32 | Финал: логотип и два QR — [t.me/vastu_sastra](https://t.me/vastu_sastra) и [vol-3.web-almanac.com](https://vol-3.web-almanac.com/) |

Переходы: склейка по заголовку, непрерывная камера по десктопу, раскрытие
кругом из узла скролла и из глифа (круг — мотив узла и прелоадера). Скорость
дублей меняется плавными рампами, быстрые моменты — с motion blur.

## Как это устроено

```
portfolio-reel/
  index.html, reel.css, reel.js   монтаж 1080×1920: какие куски дублей, с какой скоростью,
                                  куда смотрит камера, переходы, курсор/палец из трека;
                                  любой кадр — window.__reel.seek(t)
  scripts/record.mjs              съёмка дублей: приложение на виртуальных часах
  scripts/timeshim.js             виртуальное время страницы (Date, rAF, таймеры,
                                  CSS/Web Animations, <video>, GIF)
  scripts/takes.mjs               сценарии дублей: куда скроллить, что нажимать, что печатать
  scripts/mock-api.mjs            данные для съёмки (демо или реальные из data/api.json)
  scripts/fetch-api.mjs           скачать реальные данные сайта
  scripts/media.mjs               mp4 → webm и GIF → спрайты (в Chromium без H.264)
  scripts/render.mjs              покадровый рендер + motion blur + звук → MP4
  scripts/audio.mjs               сведение: трек, клики, клавиатура, переходы
  scripts/make-qr.mjs             QR-коды для финала (assets/qr)
  scripts/stills.mjs              кадры/контакт-лист для проверки
```

Дубль — это JPEG-последовательность 60 fps в `.cache/takes/<дубль>/` плюс
`track.json`: положение курсора/пальца, клики, нажатия клавиш и прямоугольники
элементов, за которыми следит камера (например, узел скролла).

## Данные

Заметки, профиль и словарь в текущем рендере — **демонстрационные**: продовый
API (`vol3.web-almanac.com`) был недоступен из среды, где собирался ролик.
Демозаметка собрана из текстов страницы «философия». Чтобы переснять с
настоящими данными — тогда в заметках откроется заметка Данилы Кудимова:

```bash
yarn build
node portfolio-reel/scripts/fetch-api.mjs     # → portfolio-reel/data/api.json
node portfolio-reel/scripts/record.mjs        # все дубли, ~30–40 мин на 4 ядрах
node portfolio-reel/scripts/render.mjs
```

## Съёмка, просмотр, рендер

Нужны Node 18+, `ffmpeg` с libx264 и Chromium для Playwright
(`npm i -g playwright && npx playwright install chromium`).

```bash
yarn build
node portfolio-reel/scripts/record.mjs --dry       # быстрый прогон сценариев (кадр раз в 12)
node portfolio-reel/scripts/record.mjs [дубль…]    # m-home d-home d-notes m-dict
node portfolio-reel/scripts/stills.mjs --sheet 4 6.5 12 26   # кадры монтажа
node portfolio-reel/scripts/render.mjs              # → portfolio-reel/out/vol3-reel.mp4
```

Превью в браузере: `npx serve .` из корня репозитория →
`http://localhost:3000/portfolio-reel/` (пробел — play/pause, `?t=12.5` —
открыть на нужной секунде).

Флаги рендера: `--from 10 --to 14` (кусок), `--samples 1` (без motion blur,
быстро), `--workers 4`, `--crf 18`, `--grain 0`, `--no-audio`.

## Для Instagram

Загружать как Reels без кадрирования. Громкость сведена к −14 LUFS. QR-коды на
финале держатся 5 секунд, их можно отсканировать с паузы или скриншота.
